# Contributing

## Code Style

- Follow Prettier and ESLint rules (`npm run lint`).
- Ensure all commits are meaningful and clear.

## Contribution Steps

1. Fork the repo.
2. Create a feature branch.
3. Commit changes.
4. Open a pull request.

```
**Steps to reproduce:**  
**Expected result:**

```
