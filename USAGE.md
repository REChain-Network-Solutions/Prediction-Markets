# Usage

## Features

- **Create Market**: Initiate a prediction market for an event.
- **Participate in Market**: Stake tokens to predict outcomes.
- **Resolve Markets**: Market resolution through community governance.

## Scripts

- `npm run dev` - Start the app in development mode.
- `npm run build` - Build production-ready app.
- `npm run test` - Run tests.

## Environment Configuration

Set parameters in `.env` such as API endpoints and contract addresses.
