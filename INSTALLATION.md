# Installation Guide

## Prerequisites
- Node.js >=14
- npm or Yarn
- Web3-enabled browser

## Steps

1. Clone repository  
   `git clone https://github.com/REChain-Network-Solutions/Prediction-Markets.git`
2. Configure environment  
   `cp .env.example .env` and update required values.
3. Install dependencies  
   `npm install`
4. Start development server  
   `npm run dev`
5. Build for production  
   `npm run build`
